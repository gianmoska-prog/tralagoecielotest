# Copy audit — v13

Scope: reviewed all visible section copy against the original Tra Lago e Cielo website and the wine-label pages.

Main copy decisions:
- Removed internal/prototype-sounding phrasing such as “visita digitale”, “prima del sopralluogo reale”, “senza frizioni”, and “il modo corretto”.
- Reduced unsupported luxury-style claims and replaced them with facts from the original site: 40,000 sqm garden, salone capacity, one wedding per day, civil ceremony in villa, parking, pool/terrace/salone/garden, contact details, and wine origin.
- Reworded wine copy so it does not imply the wines are necessarily produced on-site by the venue; it now says the labels report production and bottling by Azienda Agricola Rosalba Cutolo.
- Removed WhatsApp CTAs because the original site does not explicitly list WhatsApp as a contact method.
- Kept Instagram and Facebook contact cards because public search confirms the corresponding profiles exist.

Remaining note:
- The site still uses a refined marketing tone. It is now more factual and less AI-like, but future owner confirmation should still verify services, menu availability, and exact preferred enquiry channels.
